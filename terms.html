شرایط استفاده

آخرین به‌روزرسانی: ۱۸ سپتامبر ۲۰۲۶

۱. پذیرش شرایط

با استفاده از اپ «پی‌نما»، شما این شرایط را می‌پذیرید. اگر با آن‌ها موافق نیستید، لطفاً از اپ استفاده نکنید.

۲. شرح سرویس

پی‌نما یک ابزار اطلاعاتی جامعه‌محور برای نمایش قیمت لحظه‌ای رمزارز Pi، نرخ تبدیل، نمودار تاریخی، ماشین‌حساب، پرتفوی شخصی و هشدار قیمت است. این اپ کاملاً استاتیک است و داده‌ای روی سروری از ما ذخیره نمی‌شود.

۳. عدم ضمانت دقت داده‌ها

داده‌های قیمت از منابع عمومی ثالث (مانند CoinGecko و OKX) دریافت می‌شوند. ما برای دقت، کامل‌بودن یا به‌روزبودن این داده‌ها هیچ تضمینی نمی‌دهیم. ممکن است داده‌ها با تأخیر یا خطا نمایش داده شوند.

۴. عدم توصیه مالی

پی‌نما صرفاً ابزار نمایش اطلاعات است و هیچ‌گونه توصیه مالی، سیگنال خرید یا فروش، یا مشاوره سرمایه‌گذاری ارائه نمی‌دهد. هرگونه تصمیم معاملاتی بر عهده و مسئولیت خود شماست و ما مسئولیتی در قبال زیان‌های احتمالی نمی‌پذیریم.

۵. تبلیغات

در صورت فعال‌بودن، نمایش تبلیغات از طریق شبکه رسمی Pi Ad Network انجام می‌شود و تابع سیاست‌ها و شرایط Pi Network است. نمایش تبلیغ برای کاربر داوطلبانه است و مبنای استفاده از امکانات اپ نیست.

۶. ممنوعیت‌ها

  • استفاده از اپ برای هر فعالیتی غیرقانونی یا مغایر با شرایط استفاده Pi Network
  • تلاش برای دستکاری، مهندسی معکوس یا اختلال در عملکرد اپ
  • استفاده از ربات یا اسکریپت برای درخواست‌های انبوه به منابع داده

۷. تغییر سرویس و شرایط

ممکن است سرویس و این شرایط در آینده به‌روزرسانی شوند. ادامه استفاده پس از تغییرات به‌معنای پذیرش شرایط جدید است. نسخه جاری همیشه در همین صفحه در دسترس است.

۸. محدودیت مسئولیت

سرویس «همان‌گونه که هست» ارائه می‌شود. تا حد مجاز قانون، مسئولیت ما در قبال هر خسارت ناشی از استفاده از اپ حداکثر برابر صفر دلار است.

۹. پایان استفاده

می‌توانید هر زمان استفاده را متوقف کنید. داده‌های ذخیره‌شده روی دستگاه شما از طریق «تنظیمات ← پاک‌کردن همه داده‌ها» قابل حذف کامل است.

۱۰. ارتباط با توسعه‌دهنده

این اپ یک پروژه شخصی و جامعه‌محور است. برای سؤالات و گزارش مشکل از طریق کانال اعلام‌شده در Pi Developer Portal یا مخزن پروژه اقدام کنید.

پی‌نما وابسته به یا endorsed‌شده توسط Pi Network نیست؛ یک اپ مستقل جامعه‌محور برای اکوسیستم آن است.

      نسخه —

      For Ecosystem reviewers (English)

      PiNama is a free, open-source price tracker for Pi Network, built for Persian-speaking Pioneers. Features: live PI/USDT price (Gate.io → CoinGecko → OKX), candlestick chart (24h/7d/30d), toman conversion (Ramzinex/tgju or manual rate), portfolio valuation with daily/weekly snapshots, price alerts (quick ±5% presets), daily streak, and an offline-capable PWA. No accounts, no backend, no data collection — everything stays on the device (see Privacy). Monetization: Pi Ad Network (rewarded + interstitial, forward-nav only). Source: github.com/averageali12-afk/pinama

      ⚠️ این اپ توصیه مالی نیست. مسئولیت معامله با شماست.
